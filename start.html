This course is for beginners. Here's all you need.

What you need

You need

  • Basic Python. Lists, dictionaries, for loops, if, functions. Rusty? Try the Python tutorial.
  • Python and PyTorch installed: pip install torch
  • School math. Add, multiply, fractions, “a 50% chance”.

You don't need

  • Calculus
  • Any AI experience
  • A GPU. Any laptop works.
  • To know log, ex or matrices. We explain them when they appear.
Quick check: what does this print?
for i in range(3):
    print(i)

How to use the lessons

Learning?

  • Go in order.
  • Do each activity before reading on.
  • Guess before you click.
  • Run the Python code yourself.

Teaching?

  • Teach mode makes text big for a projector.
  • ← → keys move between parts.
  • Ask the quiz questions out loud first.
  • Let the class choose what to try in the activities.
