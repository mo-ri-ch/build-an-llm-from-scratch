# Lesson 5 plan: shared numbers (must be taught properly here)

Lessons 3 and 4 only say: "a smarter model needs far fewer boxes, but its numbers can't be counted".
Lesson 5 must teach "shared numbers" step by step, using the pairs table students already know:

1. Recap the Lesson 3 table: one row per last letter (row "t" → column "h" = 4).
2. Looking back 3 letters with counting: one row per 3-letter group ("cat", "sat", "mat" ...),
   2,744 rows, separate rows learn nothing from each other, most stay empty.
3. The smarter idea: small tables, one per position, and ADD their numbers to make one guess:
   guess after "cat" = row "t" (last) + row "a" (2 back) + row "c" (3 back)
   guess after "sat" = row "t"        + row "a"          + row "s"
   Rows "t" and "a" are used by both words: shared numbers. 3 × 196 = 588 vs 38,416.
4. Why they can't be counted: a guess is made by adding several numbers; a count says how often a
   whole pair happened, not how much each piece should add. So they must be learned (Lesson 4).
5. Only then use the term "shared number".

Note: do NOT use a single "at → space" box as the example; that one *can* be counted (it's a 2-letter table).
