Counting (Lesson 3)

Read the text. Write each count in its box: t → h seen 4 times → 4.

Only works when every number simply means “how many times this pair appeared”.

Learning (this lesson)

Start with random numbers. Guess, see how wrong, fix them a little. Repeat thousands of times.

Works for any numbers, even ones that can't be counted.

Learning repeats 4 steps:

  1. a)Predict the next character
  2. b)Measure how wrong
  3. c)Find which way to change each score
  4. d)Move each score a little

To predict, Neo needs chances, not scores. How do scores become chances?

How does softmax work?

e is a fixed number, about 2.718. escore is always positive, and a bigger score gives a much bigger result. Then divide each by the total, so they add up to 1.

scores = [2.0, 1.0, -1.0]
e^     = [7.389, 2.718, 0.368]    # total 10.475
chance = [0.705, 0.259, 0.035]

Now Neo can guess. But its scores are random, so its guesses are bad. How bad?

What is log?

You don't need the math. Just remember: −log turns a chance into a “how wrong” number. Chance 1 → 0 (perfect). The smaller the chance, the bigger the number.

chance given to the right answer0.90.50.130.01
loss0.110.692.044.61

Neo does this for all 46 pairs in the text and takes the average: 3.09 at the start. One number for how bad all its guesses are.

The goal is to make the loss small. But which of the 196 scores should change, and which way?

Which way?

c) Find directions. For each score: should it go up or down to lower the loss?

That direction is called the gradient. For one pair, t → h, it's simple:

  • The right answer (h): gradient = chance − 1. Always negative, so push it up.
  • Every wrong one: gradient = its chance. Always positive, so push it down.
Look at the gradients. Then press “Move a little”. d) Move.

PyTorch finds all 196 gradients at once with loss.backward(). To do that, it records every step of the math, then works backwards. requires_grad=True tells it to record.

Why is negative “up”?

A gradient says: if this score goes up, what happens to the loss?

Negative: the loss goes down. Good, so raise it. Positive: the loss goes up, so lower it.

With all 8 pairs, each gradient is: its chance − its goal. For space: about 0.07 − 0.375 = negative, so space goes up. That's different from the single pair t → h on the last page, where space was a wrong answer.

Doing this by hand for 196 scores would take forever. Let Neo do it.

Here's all of it in Python.

The code

Guess what each print shows. Then press ▶ Run.

import torch
import torch.nn.functional as F

text = "the cat sat on the mat. the dog sat on the log."
unique_chars = sorted(set(text))
vocab_size = len(unique_chars)
char_to_number = {}
number_to_char = {}
for number, char in enumerate(unique_chars):
    char_to_number[char] = number
    number_to_char[number] = char

# Pairs: this character, and the next one
current_chars = []
next_chars = []
for i in range(len(text) - 1):
    current_chars.append(char_to_number[text[i]])
    next_chars.append(char_to_number[text[i + 1]])
current_chars = torch.tensor(current_chars)
next_chars = torch.tensor(next_chars)

# The model: random scores. requires_grad=True lets PyTorch find gradients.
torch.manual_seed(42)
weights = torch.randn((vocab_size, vocab_size), requires_grad=True)

learning_rate = 10
for step in range(300):
    scores = weights[current_chars]                # a) predict
    loss = F.cross_entropy(scores, next_chars)     # b) measure
    weights.grad = None
    loss.backward()                                # c) find directions
    weights.data = weights.data - learning_rate * weights.grad   # d) move
    if step % 50 == 0:
        print("Step", step, "loss:", round(loss.item(), 3))

# What did it learn after 't'?
probabilities = F.softmax(weights, dim=1)
t_row = probabilities[char_to_number['t']]
for char in [' ', '.', 'h']:
    print(repr(char), round(t_row[char_to_number[char]].item(), 3))

What does each line do?
  • weights[current_chars]: copies the row of each of the 46 characters.
  • F.cross_entropy: softmax, pick the right answer's chance, −log, average.
  • weights.grad = None: clears old gradients. PyTorch adds new ones on top.
  • loss.backward(): fills weights.grad with a gradient for every score.
  • weights.data - learning_rate * weights.grad: the minus flips the sign, so negative goes up.
