Counting what comes next

The problem

Time to write my first words! Let's count which letter usually comes next.

Lesson 2 ended with a question: now that text is numbers, how do we make our first guess at the next character?

Every LLM does just this. Look at the text so far. Guess what comes next.

Read this text:
the cat sat on the mat. the dog sat on the log.
Which character comes after t most often?

Let's count which letter follows which.

Row = this character. Column = the next one. This table is counts in the code.

Counts aren't chances yet. Let's turn each row into chances.

Counts into chances

Divide each count by the row's total. Now each row adds up to 1.

Pick a row. See its chances.

These are probabilities: how likely each next character is.

Try the row for “h”. Only one character ever follows it.

Neo has chances now. Let's use them to write.

Write new text

Spin a weighted wheel. It's like a dice where likely characters get bigger faces: a bigger slice means a bigger chance.

Press “Spin”. The slice that stops under the arrow is the next character.

Real LLMs write exactly like this: one piece at a time.

See words like “sathe”? The model only looks at 1 character, so it can't tell it already finished “sat”.

Here's all of it in Python.

The code

Guess what each print shows. Then press ▶ Run.

import torch

text = "the cat sat on the mat. the dog sat on the log."

unique_chars = sorted(set(text))
vocab_size = len(unique_chars)
char_to_number = {}
number_to_char = {}
for number, char in enumerate(unique_chars):
    char_to_number[char] = number
    number_to_char[number] = char

# Count pairs. Row = this character, column = next one.
counts = torch.zeros((vocab_size, vocab_size))
for i in range(len(text) - 1):
    row = char_to_number[text[i]]
    column = char_to_number[text[i + 1]]
    counts[row, column] = counts[row, column] + 1

# Counts into chances: divide by each row's total
row_totals = counts.sum(dim=1, keepdim=True)
probabilities = counts / row_totals

t_row = probabilities[char_to_number['t']]
for number in range(vocab_size):
    if t_row[number] > 0:
        print(repr(number_to_char[number]), round(t_row[number].item(), 3))

# Write new text: spin the weighted wheel 40 times
torch.manual_seed(42)
current = char_to_number['t']
output = 't'
for step in range(40):
    picked = torch.multinomial(probabilities[current], num_samples=1)
    current = picked.item()
    output = output + number_to_char[current]
print(output)

What do sum(dim=1, keepdim=True) and multinomial mean?

dim=1 adds up across each row. keepdim=True keeps one total per row, so each row is divided by its own total.

torch.multinomial(chances, num_samples=1) is the weighted wheel. It picks 1 position, where bigger chances are picked more often.
