Text into numbers

The problem

I see letters everywhere, but they mean nothing to me. Can you turn them into numbers?

An LLM reads text, but tensors hold only numbers. How do we turn text into numbers?

🤔 What if a character isn't in the vocabulary?

There is no number for it, so encode gives an error (like “help”: no p). A model can only use characters in its vocabulary, so the text must have every character we need.

The code

Guess what each print shows. Then press ▶ Run.

import torch

text = "the cat sat on the mat. the dog sat on the log."

# Find every different character, sorted
unique_chars = sorted(set(text))
print(unique_chars)

# Give each one a number, and the reverse
char_to_number = {}
number_to_char = {}
for number, char in enumerate(unique_chars):
    char_to_number[char] = number
    number_to_char[number] = char

# Text -> numbers
def encode(some_text):
    numbers = []
    for char in some_text:
        numbers.append(char_to_number[char])
    return numbers

# Numbers -> text
def decode(numbers):
    result = ""
    for number in numbers:
        result = result + number_to_char[number]
    return result

print(encode("cat"))

print(decode([4, 11, 6]))

# The whole text as a tensor
print(torch.tensor(encode(text)))
