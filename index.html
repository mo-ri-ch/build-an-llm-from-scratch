Build a tiny LLM from scratch, one question at a time.

Every chatbot does one thing over and over: guess the next piece of text. In these lessons you build that guesser yourself, starting from a list of numbers, and you can see every step it takes.

    How to use these lessons

    If you're learning

    1. Go in order. Each lesson needs the one before it.
    2. When a box says “predict first”, really guess before you click.
    3. Run the Python code yourself and compare with the outputs shown.
    4. Stuck? Open the “Still unclear?” boxes. They explain the same idea a different way.

    If you're teaching

    • Press Teach mode on any lesson for big text. The ← and → keys move between parts.
    • Ask the “predict first” questions out loud before revealing them.
    • Use the interactive parts as live demos and let the class choose what to try.
    • The open question at the end of each lesson makes a good homework question.
    The Python code for every lesson is in the GitHub repository. Your progress is saved in this browser only.
